# 2026-08-19 工作日志

## occ 可视化坐标系修复

**问题**：`vis_fastbev_occ_results.py` 和 `vis_occ.py` 中 occ 显示结果不正确，需要逆时针旋转 90 度才正确。

**根因**：occ GT 标注和模型预测的维度排列是 `(Y, X, Z)` 而非 `(X, Y, Z)`。即 occ 数组的 dim0 是 Y 轴（左向），dim1 是 X 轴（前向），dim2 是 Z 轴（高度）。

**验证方法**：通过对比 GT occ 中 car/ped 等类别体素的空间位置与 GT 3D 检测框的中心坐标，确认 dim0=Y, dim1=X。例如 frame 0 的 GT box car 中心在 lidar 坐标 (-0.6, -24.0)，而 occ car 体素质心在 (-22.5, 0.5)，交换 x/y 后 (0.5, -22.5) ≈ (-0.6, -24.0)，确认维度排列为 (Y, X, Z)。

**修复**：
- `tools/vis_fastbev_occ_results.py` 第 210 行：`occ_rgb.transpose(1, 0, 2)[::-1, :, :]` → `occ_rgb[::-1, :, :]`
- `tools/analysis_tools/vis_occ.py` 第 209 行：同上修复
- 两个文件的 `occ_to_bev_rgb` 注释也同步修正

**原理**：lidar 画布映射为 col=x(前→右), row=-y(左→上)。occ 标注 dim0=Y, dim1=X，正确的画布映射仅需翻转 dim0(Y)：`canvas[row, col] = occ[199-row, col]`，即 `occ[::-1, :, :]`。之前的 `transpose(1,0,2)[::-1]` 错误地假设了 dim0=X, dim1=Y，导致 occ 显示旋转了 90 度。

**注意**：FlashOCC 的 `vis_occ.py` 使用 Open3D 3D 渲染，`voxel2points` 直接将 `occIdx[0]→x, occIdx[1]→y` 映射到 3D 坐标。但 FlashOCC 的 occ 标注维度排列可能不同（需进一步确认）。

## 最终结论：occ GT 维度排列

occ 标注维度排列为 **(Y, -X, Z)**：
- dim0=Y：正向=左（与 lidar Y 一致）
- dim1=-X：正向=**后向**（与 lidar X 相反！）
- dim2=Z：高度

**验证方法**：对比 frame 0 的 GT occ car 体素位置与 GT 3D box 中心：
- Car box 0: x=-0.6, y=-24.0
- Car occ 体素: dim0=37-47, dim1=99-103
- 若 dim1=-X: x_m=[-1.2, -0.4] ≈ box x=-0.6 ✓
- 若 dim1=X: x_m=[0.4, 1.2] ≠ box x=-0.6 ✗

同样验证行人（box 3: x=-23.6, y=38.1）：
- Ped occ 体素: dim0=182-199, dim1=129-162
- 若 dim1=-X: x_m=[-24.8, -11.6] ≈ box x=-23.6 ✓

**画布映射修正**：`[::-1, :, :]` → `[::-1, ::-1, :]`（同时翻转 dim0(Y) 和 dim1(-X)）
- dim0=Y: 翻转使 y正(左)→row0(上) 
- dim1=-X: 翻转使 x正(前,即dim1小值)→col大(右)

此修正已应用于三个文件：
- `tools/vis_fastbev_occ_results.py`
- `tools/analysis_tools/vis_occ.py`
- `tools/vis_fastbev_occ_gt.py`

**新文件**：`tools/vis_fastbev_occ_gt.py` — 可视化 nuScenes GT 数据（不含推理结果）。

**功能**：显示激光点云、GT 3D 检测框（黄色）、6 通道相机图像、GT occ 真值，布局与 `vis_fastbev_occ_results.py` 完全一致。

**数据来源**：
- val infos pkl: `data/nuscenes/bevdetv3-nuscenes_infos_val.pkl`（含 `gt_boxes`, `lidar_path`, `cams`, `occ_path`）
- GT occ: `infos['occ_path']/labels.npz` 中的 `semantics` 字段 (200,200,16) [Y,X,Z]

**用法**：
```bash
conda activate bev
python tools/vis_fastbev_occ_gt.py \
    --pkl data/nuscenes/bevdetv3-nuscenes_infos_val.pkl \
    --save-path work_dirs/vis_gt --frames 0-199
```
