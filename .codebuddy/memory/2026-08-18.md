# 2026-08-18 工作日志

## train.py 修复：支持位置参数指定 GPU 数量

**问题**：运行 `python tools/train.py projects/configs/flashocc/flashocc-r50.py 2` 时，argparse 报错 `unrecognized arguments: 2`，因为 `2` 没有对应的位置参数定义。

**修复**：在 `tools/train.py` 的 `parse_args()` 中，在 `config` 位置参数后添加了可选位置参数 `gpu_num`（`nargs='?', type=int, default=None`），并在参数解析后将 `gpu_num` 映射到 `args.gpus`，使命令行中可直接传入 GPU 数量。

**验证**：用模拟 argparse 验证 `['config.py', '2']` 和 `['config.py']` 两种场景均正常解析。

**注意**：当前 conda 环境 `bev` 有 mmcv 依赖，但默认 shell 环境中没有。用户需要激活正确的 conda 环境来运行训练脚本。
